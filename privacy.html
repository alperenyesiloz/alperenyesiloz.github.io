Privacy Policy

Last updated: November 22, 2026

shorts-factory is a personal tool used only by its owner. It is not offered to the public.

Data accessed

With the owner's permission, through Google OAuth, the tool accesses the owner's own YouTube channel to upload videos, read channel analytics, and read comments on the owner's videos.

How data is used

This data is used only to publish videos and to improve future videos on the same channel. It is never sold, shared with third parties, or used for advertising.

Storage

Access tokens and channel statistics are stored only on the owner's own computer. No data from other users is collected.

YouTube API Services

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google Account permissions page.
